### Fixes

- **Repeated clicks in a match**: clicking several times in a row on Attack, Pass, an ability or a card (while the first action was still being processed) caused internal rejections from the server. Now only one action travels at a time: extra clicks are simply ignored and the buttons re-enable when the response arrives. Nothing changes in how the game plays — it just makes the game more stable.
