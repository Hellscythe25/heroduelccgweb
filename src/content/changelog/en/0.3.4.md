### Improvements

- **Faster, lighter startup**: the game no longer downloads the full card catalog on every launch — it stores it on your computer and only downloads it again when there are new cards or balance changes. The number of server calls at startup and when returning to the menu after a match was also reduced. Nothing changes in how the game plays.
